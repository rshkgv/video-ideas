Стол за один жест

Пользователь стоит перед голым, пустым учебным столом — ни одной вещи, только столешница. С первого кадра виден фирменный жёлтый значок «TikTok Shop». Одним широким жестом руки слева направо он проводит вдоль стола — и по ходу движения руки на столешнице материализуются, будто разложенные невидимым продавцом, органайзеры, настольная лампа, стакан для ручек, ноутбук на подставке: полностью укомплектованное учебное место. Пользователь опускает руку, оборачивается к камере с довольной улыбкой, обводя взглядом готовый стол — классический приём «одним жестом всё появилось», типичный для шоппинг-роликов.
