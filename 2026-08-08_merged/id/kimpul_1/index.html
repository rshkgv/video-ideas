#kimpul

Пар из шарика кимпул

Пользователь сидит за домашним кухонным столом перед тарелкой золотистых обжаренных шариков кимпул с кетчупом — ровно тот кадр, которым живёт тренд. Он берёт один шарик обеими руками и решительно разламывает его пополам: корочка хрустит, из разлома вырывается настоящий пар, внутри — мягкая рассыпчатая светлая начинка. Пауза в полсекунды — и только затем по лицу расползается беззвучная довольная улыбка, он тут же откусывает половину. Никакой речи — только жест и немая реакция удовольствия. Визуальный якорь: домашняя кухня с белыми шкафчиками, тарелка золотистых обжаренных шариков кимпул с кетчупом на белом столе, повседневная рубашка и хиджаб, пар из разломанного шарика в руках пользователя.
